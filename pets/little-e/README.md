# Little E

Little E is a pocket-sized Eureka work buddy: curious, practical, and quietly playful.

## Install

From the repository root, run in PowerShell:

~~~powershell
Copy-Item -Path pets/little-e -Destination ~/.eureka/pets/little-e -Recurse
~~~

Then select **Little E** in Settings > Appearance > Desktop Pet. If it is already selected, restart Eureka to reload cached stickers.

## Contents

- [pet.json](pet.json) defines the pet profile, state mappings, and English/Chinese chatter.
- [stickers/](stickers/) contains 18 WebP stickers covering idle (including sleeping), thinking, needs input, steer, complete, and error states.

The manifest and stickers were copied unchanged from the locally installed Eureka Little E pet.
